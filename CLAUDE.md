# FamilySearch Memories — Logged-Out Experience Exploration

## Project Focus
This project explores the logged-out experience for FamilySearch Memories, specifically around searching and previewing public memories before account creation.

The primary focus is helping potential new users:
- discover public memories,
- preview meaningful metadata,
- and understand the value of Memories before creating an account.

## Core Goals
- Create a clearer and more intentional logged-out discovery experience
- Improve memory search and preview experiences
- Explore lightweight “sneak peek” interactions for public memories
- Define clearer preview boundaries between public exploration and account-required interactions
- Encourage curiosity and continued exploration without making the experience feel restrictive

## Current Exploration Areas
- Public memory search flows
- Memory search result layouts
- Metadata visibility and hierarchy
- Memory preview interactions
- Overlay/modal gating patterns
- Account prompts and interaction boundaries
- Exploration continuity between search, people, and memories

## Key Research Insights
- FamilySearch currently provides more open exploration than competitors
- Competitors use stronger preview boundaries and clearer interaction gating
- Missing metadata can make memories feel incomplete or broken
- Overlay-based prompts preserve exploration momentum better than full-page redirects
- Search and discovery experiences should feel intentional and easy to navigate
- Potential new users benefit from previewing value before account creation

## Current Goal
Explore and map possible logged-out user flows and interaction models before moving into UI design or prototyping.

Focus on:
- user journeys,
- interaction patterns,
- preview behaviors,
- and discovery flows.

Avoid jumping directly into polished UI solutions.
